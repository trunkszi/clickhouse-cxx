This file is the authoritative operational contract for coding agents (OpenAI Codex, Claude Code, Gemini CLI) working in clickhouse-cxx.

## Project Overview

`clickhouse-cxx` is a thread-affine, completion-driven ClickHouse client SDK for Rust (`edition = "2024"`, `license = "Apache-2.0"`):
- Native TCP and TCPS use `clickhouse-cpp` 3.x bridged through `cxx`, with Native socket I/O on `liburing::Proactor` and DNS on `cares::ProactorResolver`.
- HTTP and HTTPS use `nexora-rs` (`main` branch) with HTTP/1.1, HTTP/2, and `rustls`.
- Typed row schemas, struct-of-arrays batches, zero-copy views, and borrowed row references are generated by `#[derive(Row)]` (`clickhouse-macros`).
- Serde-only types interoperate through `SerdeBridge` (`RowBinary`, `RowBinaryWithNamesAndTypes`, and `Block` conversions).

## Crate Layering & Features

Dependency direction is strictly downward:

```text
clickhouse-sys    -> (FFI and Native I/O: cxx, cmake, rustls, liburing, cares, libc)
clickhouse-macros -> (leaf proc-macro crate: syn, quote, darling)
clickhouse        -> clickhouse-macros, optional clickhouse-sys (tcp), optional nexora/lz4_flex/zstd (http)
```

Feature matrix on `crates/clickhouse`:
- `default = ["tcp"]`
- `tcp`: enables `dep:clickhouse-sys` and `dep:cxx` for Native `tcp://` and `tcps://` transports.
- `http`: enables `dep:nexora`, `dep:lz4_flex`, and `dep:zstd` for `http://` and `https://` (`FORMAT Native`, `FORMAT RowBinary`, `FORMAT ArrowStream`). An `--no-default-features --features http` build never compiles `clickhouse-sys`.
- `tracing`: enables cold control-plane telemetry (connection lifecycle, failover, `OnServerLog`). Data-plane reads and writes emit zero logs.

`crates/clickhouse-sys/build.rs` resolves `clickhouse-cpp` sources in order:
1. `CLICKHOUSE_CPP_DIR` environment variable
2. `../../vendor/clickhouse-cpp`
3. `target/vendor-cache/clickhouse-cpp`

No hardcoded machine-specific absolute paths are permitted in `build.rs` or any manifest.

## Hard Invariants & Coding Standards

- **ASCII English**: Keep every tracked file ASCII-only and at most 800 lines.
- **100% English**: all source comments, docstrings, error messages, logs, test fixtures, commit messages, and documentation must be written in English.
- **File size limit**: Split modules and documentation by responsibility before exceeding 800 lines. Cargo regenerates its ignored lockfile locally; publish library dependency constraints in the manifests.
- **Module cohesion**: Group code by behavior and ownership; file length alone does not define a module. Keep private tests inline in `#[cfg(test)]` modules and public interface tests under `tests/`. Standalone `tests.rs`, `*_tests.rs`, and `test_support.rs` files belong outside `src/`.
- **Dependency graph**: Audit resolved development and build dependencies alongside owned manifests and source.
- **Inline dependency tables**: every dependency entry in every `Cargo.toml` must use single-line inline table syntax (e.g., `serde = { workspace = true }`), never `[dependencies.foo]` sections.
- **Domain naming**: use `WireBlock`, `WireColumn`, `FixedWireColumn`, `WireError`, `column/`, and `wire_block.rs`. Do not introduce `cpp_*` or `Cpp*` identifiers in `crates/clickhouse` or `crates/clickhouse-macros`.
- **Safety & rustdoc lints**:
  - Every `unsafe` block must have a preceding `// SAFETY:` comment explaining the invariant.
  - Every `unsafe fn` must include a `# Safety` doc section.
  - Every public fallible or panicking function must document `# Errors` and `# Panics` as enforced by workspace clippy lints.
  - Redundant clones (`clone_on_copy`, `redundant_clone`, `implicit_clone`, `unnecessary_to_owned`) and `todo!` / `unimplemented!` macros are denied across the workspace.

## Execution, Zero-Copy, and Buffer Invariants

- **Completion-driven and thread-affine**:
  - Expose nonblocking HTTP admission through `submit_http`, one bounded I/O turn
    through `poll_http`, result extraction through `HttpRequest::try_take`, and
    explicit owner-checked cancellation through `cancel_http`.
  - Preserve the synchronous Native C++ ABI and convenience HTTP methods. Native
    stream adapters advance SQEs to completion without blocking socket syscalls.
    Describe this waiting boundary accurately; it is not a resumable Native query.
  - Keep the dependency graph free of external executor runtimes.
  - `Client`, transport handles, `Proactor`, and `TlsSession` are `!Send + !Sync`. Sockets, blocks, views, and callbacks remain on the thread that created them; the I/O path uses no blocking locks.
  - Multi-threaded scaling uses `ThreadLocalClient` (one `Client` per calling OS thread) or `WorkerClient` (`0..N` lock-free slots leased on the calling thread via `ClientConfig::with_workers(N)`, striped across endpoints with `endpoints[(worker_id + step) % len]`).
  - Failover callbacks (`ClientConfig::on_failover`) use single-threaded `FnMut` and `Rc<RefCell<_>>` on the calling thread.
- **Zero-copy & borrowed inputs**:
  - APIs taking strings or bytes accept `&str`, `&[u8]`, `Cow<'a, str>`, or `Cow<'a, [u8]>`.
  - `BlockView<'a>` projects fixed-width columns as `&'a [T]` over native column memory via `zerocopy`; string, array, nullable, and map projections borrow directly from the backing `Block`.
- **Reusable buffers & streaming reads**:
  - `Batch` and `Block` reuse capacity across cycles via `clear()` and `clear_with_policy(BufferPolicy)`. `BufferPolicy::default()` caps retained capacity at 65,536 rows and 8 MiB.
  - Streaming callback reads (`query_views`, `query_row_refs`, `query_for_each`, `query_raw_with`, `SerdeBridge::*_with`) process data while the backing buffer is alive without intermediate `Vec<T>` allocation.
  - Caller-supplied destination reads (`read_into_slice`, `read_bytes_into`, `query_rows_into_slice`, `query_batch_into`, `query_block_into`, `query_raw_into`, `query_raw_into_slice`, `SerdeBridge::*_into_slice`) write into caller-owned memory.

## HTTP Runtime Contracts

- Own `nexora::HttpClient` and `nexora::Proactor` on the calling thread with a
  `PhantomData<Rc<()>>` affinity marker. Drive requests through `submit` and
  `drive`. Call `shutdown` before rebuilding or dropping the driver, and keep
  client destruction before proactor destruction. Keep nonblocking admission
  free of teardown loops: apply pending configuration through the explicitly
  synchronous `reset_http` boundary. Keep stream-local failures request-local.
- Pin IP literals through `HttpClient::resolve_host`; let Nexora resolve
  hostnames through c-ares within the request deadline.
  Send POST requests with structured authentication and compression headers.
- Map `Http1` to both protocol flags false; map `Http2PriorKnowledge` to both
  true; map `Http2Tls` and `Negotiate` to preference true and prior knowledge
  false. Default to `Negotiate`; require HTTPS and a negotiated HTTP/2 response
  when the caller explicitly selects `Http2Tls`. Offer only h2 through ALPN for
  that choice and set its request version to HTTP/2, so a peer omitting ALPN
  cannot route a POST through the HTTP/1.1 codec before rejection.
- Keep redirects disabled. Surface transport failures as `Error::HttpTransport`
  and status or ClickHouse exception responses as `Error::Http`, including when
  their diagnostic body cannot be decoded.
- Read content encoding and exception codes from structured response headers.
  Bound encoded and decoded bodies independently to 256 MiB.
- Nexora collects the encoded response before completion. Deliver decompressed
  chunks directly to a borrowed receiver on the caller stack; preserve callback
  errors and panic propagation. Describe this buffering boundary accurately.

## Native Ring Contracts

- Retain one Native proactor and a fixed 1 MiB DMA allocation per calling thread.
  Keep Native descriptors nonblocking and close-on-exec; prepare connect, receive,
  and send SQEs against stable owned operands.
- Resolve IP literals directly and hostnames with c-ares on the same ring. Apply
  one absolute budget to DNS and all candidate connection attempts.
- Keep target buffers, descriptors, addresses, and timespecs alive through final
  CQEs. A cancellation CQE alone never permits reuse. Drain target, timer, and
  cancellation completions before the next operation; quarantine on failed drain.
  Propagate failed timer and fatal cancellation CQEs immediately into retirement.
  Successful cancellation and not-found/already-running races still require the
  referenced operation's final CQE before reuse. Only expiry and explicitly
  requested timer cancellation are valid deadline completions.
- Production adapters use ring operations. Controlled test-only TCP peers may
  use bounded conventional sockets in tests/ or final inline test modules. Use
  per-thread test counters or atomic flags for peer coordination.
