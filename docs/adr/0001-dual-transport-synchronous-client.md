# Dual-Transport Synchronous Client over Native C++ (`cxx`) and `curl-rust` (`rustls`)

ClickHouse's official Rust ecosystem requires an asynchronous `tokio` runtime, which is incompatible with synchronous, low-latency, or reactor-isolated Rust codebases. We decided to build a purely synchronous `Client` that unifies two statically linked transports behind URL-scheme routing: `clickhouse-cpp` bridged via `cxx` for the column-oriented Native TCP protocol (`tcp://`, `tcps://`), and `curl-rust` (`feat/event-loop-ws` branch, backed by `rustls-ffi`) for HTTP/HTTPS (`http://`, `https://`). OpenSSL is completely excluded across both stacks (`-DWITH_OPENSSL=OFF` in CMake); TLS on Native TCP (`tcps://`) is provided by injecting a custom C++ `SocketFactory` backed by Rust's `rustls`.
